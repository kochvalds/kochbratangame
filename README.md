## 🔥 Что нового в версии v1.8.0:

### 🌟 1. Интерфейс в стиле Brawl Stars (Brawl Stars UI)
- **Профиль Бойца (Top-Left)**: Аватарка, имя бойца, шкала трофеев (🏆 14,250) и ранговая плашка (Ранг 1-35).
- **Капсулы Ресурсов**: Стильные 3D-капсулы для жетонов 🎟️, гемов 💎 и ауры ⚡.
- **Объёмные 3D-кнопки**: Навигация и кнопки действий с фирменной глубиной и сочными цветами Supercell/Brawl Stars.

### 🔄 2. Переворот экрана и альбомный режим (Flip Screen / Landscape)
- Кнопка **«🔄 Перевернуть экран»** прямо в верхней панели: переключение между альбомным (Landscape), перевернутым альбомным (Reverse Landscape) и портретным режимами.
- Полная поддержка `fullSensor` и динамической ориентации без перезапуска активностей.

### 🎒 3. Полноценный Личный Инвентарь (Inventory System)
- Отдельный раздел **«Инвентарь»** со всеми собранными предметами:
  - 🔢 **Коллекция Госномеров РФ**: список всех выбитых номеров с категориями редкости, бонусами и кнопкой «Установить на тачку».
  - 🏎️ **Автопарк**: все приобретённые автомобили из 150 доступных моделей.
  - 🏰 **Недвижимость**: купленные особняки, пентхаусы и доходные объекты.
  - 🧖‍♂️ **Банные Гибриды**: выведенные на пару бойцы с постоянными бонусами.
  - 🪙 **Крипто-кошелек**: оценка всех монет в ауре и текущие балансы.

### 🚀 4. Покупка Криптовалюты «НА ВСЕ ДЕНЬГИ» (ALL-IN)
- Новая кнопка **«НА ВСЁ 🚀»** в криптобирже: моментальная покупка выбранной монеты (BTC, ETH, TON, MOG, MEME) на весь доступный баланс ауры.

### 🐛 5. Исправление багов и надёжные сохранения (Room DB v5)
- Исправлен баг со сбросом купленных автомобилей, номеров, недвижимости и баланса крипты: теперь абсолютно всё автоматически сохраняется в базе данных **Room v5**.
- **Удалена назойливая награда за вход в игру** — чистый и непрерывный геймплей без всплывающих окон при старте.

### 💻 6. Версии для Debian, Arch Linux, Windows и Android
- **Debian / Ubuntu**: готовый deb-пакет `looksmax-clicker_1.8.0_all.deb` и скрипт установки `install_debian.sh`.
- **Arch Linux / Manjaro**: официальный `PKGBUILD` и скрипт `install_arch.sh`.
- **Windows**: удобный `LooksmaxClicker.bat` и PowerShell-лаунчер `run_windows.ps1`.
- **Android**: оптимизированный APK для телефонов и планшетов.

## 🚀 Установка на ПК

### Debian / Ubuntu / Linux Mint:
```bash
sudo dpkg -i looksmax-clicker_1.8.0_all.deb || sudo apt install -f -y
looksmax-clicker
```

### Arch Linux / Manjaro:
```bash
cd arch && makepkg -si
looksmax-clicker
```

### Windows:
Дважды кликните по файлу `LooksmaxClicker.bat` в папке `windows`.
