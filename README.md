# Looksmax Clicker (kochvalds/kochbratangame) 🤫🧏

**Looksmax Clicker: Koch & Vlados Edition** — мемная игра-кликер для Android в стиле луксмаксинга, моггинга и братской кочалки!

Твоя цель — могать фоидок, наносить сокрушительные удары бонсмешинга, прокачивать челюсть до бритвенной остроты, автоматизировать накопление ауры через привычки привлекательности, кочнуть в зале и пройти путь эволюции от Сойджака до Истинного Гигачада и Апекс Бога Луксмакса!

## 🎮 Основные механики игры

1. **Моггинг по лицу**:
   - Кликай по персонажу на главном экране.
   - Комбо-серии (до x3!), всплывающие луксмакс-мемы (`MOGGED!`, `HUNTER EYES!`, `CANTHAL TILT!`, `BYE BYE 🤫🧏`).
   - Звуковой удар и виброотклик на каждом тапе.

2. **Бонсмешинг & Прокачка Челюсти**:
   - Бонсмешинг молотком для стимуляции кости челюсти.
   - 7 уровней апгрейдов челюсти: Мьюинг, Бонсмешинг молотком, Мастика, Квадратный подбородок, Острый гониальный угол (90°), Hollow Cheeks, Алмазная Челюсть Моггера.

3. **Автоматизация привлекательности (Пассивный доход ауры)**:
   - Пассивный моггинг каждую секунду.
   - 7 луксмакс-привычек: Ледяное умывание, SPF 100 & Ретинол, Хантер Айз, Положительный кантус, Ночной мьюинг, Походка Сигмы, Свита Моггеров.

4. **Кочалка «Кочнуть Братана» (Koch Energy Booster)**:
   - Заряжай шкалу адреналина ударами.
   - Нажми **«КОЧНУТЬ БРАТАНА»** для входа в **Режим Кочалки**:
     - Пульсирующий экран ярости, множитель клика **x2.5**, пассивный доход **x2.0**!
     - Апгрейды: Турники и брусья, Креатиновый заряд, Жим 140кг, Дух Братана (Kochvalds Legacy).

5. **Система Эволюции Профиля (7 стадий PSL)**:
   - Stage 1: **Подзаборный Сойджак** (PSL 1.5)
   - Stage 2: **Случайный Нормис** (PSL 3.2)
   - Stage 3: **Адепт Мьюинга** (PSL 4.8)
   - Stage 4: **Перспективный Чадлайт** (PSL 6.2)
   - Stage 5: **Коч Братан (Koch Mogger)** (PSL 7.5)
   - Stage 6: **Истинный Гигачад** (PSL 8.5)
   - Stage 7: **Апекс Бог Луксмакса** (PSL 9.9)

6. **Офлайн-прогресс и автосохранение**:
   - SQLite база данных через Room. Накопление ауры офлайн.
