# Looksmax Clicker (kochvalds/kochbratangame) 🤫🧏

**Looksmax Clicker** — мемная игра-кликер для Android в стиле луксмаксинга, моггинга и братской кочалки!

Твоя цель — могать фоидок, наносить сокрушительные удары бонсмешинга, прокачивать челюсть до бритвенной остроты, автоматизировать накопление ауры через привычки привлекательности, кочнуть в зале и пройти путь эволюции от Сойджака до Истинного Гигачада и Апекс Бога Луксмакса!

---

## ⚡ Особенности игры

1. **Моггинг фоидок по лицу**:
   - Кликай по лицу самодовольного фоидки на главном экране.
   - Динамическая реакция на удары, комбо-множители (до x3!), всплывающие луксмакс-мемы (`MOGGED!`, `HUNTER EYES!`, `CANTHAL TILT!`, `BYE BYE 🤫🧏`).
   - Тактильный отклик (haptic feedback) при каждом тапе.

2. **Бонсмешинг & Прокачка Челюсти**:
   - Бонсмешинг молотком для стимуляции утолщения кости челюсти.
   - 7 уровней челюстных апгрейдов:
     - Базовый Мьюинг
     - Бонсмешинг молотком
     - Жевательный тренажер & Мастика
     - Квадратный подбородок
     - Острый гониальный угол (90°)
     - Полые щеки (Hollow Cheeks)
     - Алмазная Челюсть Моггера

3. **Автоматизация привлекательности (Пассивный доход ауры)**:
   - Пассивный моггинг окружающих каждую секунду.
   - 7 луксмакс-привычек:
     - Ледяное умывание & Гуаша
     - Солнцезащитный крем SPF 100 & Ретинол
     - Тренировка Хантер Айз (Hunter Eyes)
     - Положительный кантус (Positive Canthal Tilt)
     - Ночной мьюинг (техника сна с прижатым языком)
     - Походка и осанка Сигмы
     - Свита Моггеров

4. **Кочалка «Кочнуть Братана» (Koch Energy Booster)**:
   - Накапливай адреналин кликами по фоидке или бонсмешингом.
   - При 100% заряде нажми **«КОЧНУТЬ БРАТАНА»**:
     - Включение **Режима Кочалки** на 20+ секунд!
     - Пульсирующий экран, множитель клика **x2.5**, пассивный доход **x2.0**!
     - Апгрейды: Турники и брусья, Креатиновый заряд, Жим 140кг, Дух Братана (Kochvalds Legacy).

5. **Система Эволюции Профиля (7 стадий PSL)**:
   - Stage 1: **Подзаборный Сойджак** (PSL 1.5)
   - Stage 2: **Случайный Нормис** (PSL 3.2)
   - Stage 3: **Адепт Мьюинга** (PSL 4.8)
   - Stage 4: **Перспективный Чадлайт** (PSL 6.2)
   - Stage 5: **Коч Братан (Koch Mogger)** (PSL 7.5)
   - Stage 6: **Истинный Гигачад** (PSL 8.5)
   - Stage 7: **Апекс Бог Луксмакса** (PSL 9.9)

6. **Офлайн-прогресс и автосохранение**:
   - Игра сохраняет данные в локальную базу SQLite через Android Room.
   - При возвращении в игру начисляется накопленная за время отсутствия аура.



### Запуск через Android Studio
1. Открой Android Studio.
2. Выбери **File -> Open...** и укажи папку с этим проектом.
3. Дождись завершения синхронизации Gradle.
4. Выбери эмулятор или физическое Android-устройство и нажми зеленую кнопку **Run (Shift+F10)**.
